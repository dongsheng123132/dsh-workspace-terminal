# dsh-workspace-terminal

An U-King-style right-side multi-agent terminal dock for DeepSeek Harness. It embeds real PTY tabs for Claude Code, Hermes, Codex, and a shell while the DSH conversation remains visible. DSH can coordinate with user-opened tabs through three bounded tools: `uking_terminal_list`, `uking_terminal_read`, and `uking_terminal_send`.

See [README.zh-CN.md](README.zh-CN.md) for installation, behavior, and security details.
